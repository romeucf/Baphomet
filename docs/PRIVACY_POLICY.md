# Política de Privacidade — Baphomet

O Baphomet respeita a privacidade de todos os usuários e servidores nos quais opera.

## 1. Coleta de Dados
O bot coleta estritamente as informações necessárias para seu funcionamento:
- Identificadores numéricos públicos do Discord (`User ID`, `Guild ID`, `Channel ID`, `Role ID`).
- Registros de mensagens temporárias para moderação (Anti-Spam) e métricas de atividade de membros.
- Dados de configuração fornecidos explicitamente por administradores do servidor.

## 2. Uso dos Dados
Os dados coletados são usados exclusivamente para:
- Atribuição de experiência (XP) e níveis.
- Recursos de Vínculos e Conquistas Secretas.
- Moderação automatizada e logs de punições.
- Funcionalidades como Álbum do Dia (AOTD), Filme do Dia (MOTD) e Starboard.

## 3. Armazenamento e Segurança
Os dados são armazenados localmente em bancos SQLite e em cache temporário Redis com criptografia em trânsito. Nenhum dado é compartilhado, comercializado ou transferido para terceiros.

## 4. Remoção de Dados
Administradores podem solicitar o reset total de dados de seus servidores a qualquer momento através dos comandos de configuração.
